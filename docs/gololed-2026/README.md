# Ретропроверка правил гололёда и снегопада на ДТП (исследование погоды, 2026-11-17; пересчёт 2026-11-18)

| Файл | Что это |
|---|---|
| `era5_nsk_daily_2015_2026.json` | суточная погода ERA5 по точке города (сетка 55,0; 83,0), 2015-01-01 … 2026-01-31: Open-Meteo Historical Weather API, `models=era5` |
| `ice_dtp_protokol.txt` | вывод `scripts/ice_retro/ice_dtp_check.py` на этих данных |

ДТП — открытые данные ДТП-Стат по Новосибирской области, https://dtp-stat.ru/opendata
(условие использования — активная ссылка на сайт). Файл `novosibirskaia-oblast.geojson`
(63 МБ, скачан 2026-11-17, SHA-256 `44a588122cb3cb05ff02e0bf82dc775f746252ab726d93fa17bf2687ee62d7b4`) в репозиторий не входит: его
надо скачать заново.

```bash
python3 -I scripts/ice_retro/ice_dtp_check.py novosibirskaia-oblast.geojson docs/gololed-2026/era5_nsk_daily_2015_2026.json
```

**Поправка 2026-11-18.** Расчёт 17.11 брал погоду из архива Open-Meteo без явной модели — для
2017+ это ECMWF IFS (сетка 55,079; 82,994), а не ERA5, — и окно октябрь–апрель. Отсюда числа
исследования «0,33 против 0,97, POD 0,13, FAR 0,79» и «снегопад: 1,43 против 0,72». На ERA5 за
ноябрь–март выводы те же, числа — в протоколе.
